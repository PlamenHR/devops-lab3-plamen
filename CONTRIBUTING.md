# Contributing

## Branch naming

Use short, descriptive branch names related to the task or issue.

Examples:

- `t03-service-docs`
- `t04-runbook`
- `t05-codeowners`

## Commit messages

Commit messages should be short, clear, and describe the change.

Examples:

- `Complete service documentation`
- `Complete runbook`
- `Add CODEOWNERS`

## Pull Requests

Every task must be completed through a Pull Request.

Rules:

- Do not commit directly to `main`.
- Each task must use a separate branch.
- Each Pull Request must reference the related Issue.
- The Pull Request must be reviewed by the other participant.
- At least one approval is required before merging.
- Resolve review comments before merging.
