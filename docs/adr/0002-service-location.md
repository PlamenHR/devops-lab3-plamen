# 0002. Къде работи услугата

**Status / Статус:** Proposed

## Context / Контекст

Трябва да определим къде да се стартира Notes API по време на разработката и упражненията. Решението трябва да бъде лесно за използване от всеки член на екипа и да съответства на описанията в runbook-а.

## Options / Варианти

### 1. Локално на компютъра на разработчика

Плюсове:
- Лесно стартиране.
- Не е необходим допълнителен софтуер.
- Подходящо за разработка и упражнения.

Минуси:
- Средата може да се различава между различните компютри.
- Зависимостите трябва да бъдат инсталирани локално.

### 2. В Docker container

Плюсове:
- Еднаква среда за всички разработчици.
- По-добра изолация на зависимостите.

Минуси:
- Изисква Docker.
- Добавя допълнителна сложност за текущото упражнение.

## Decision / Решение

За текущите упражнения услугата ще се стартира локално на компютъра на разработчика на `127.0.0.1:8000`.

Docker container може да бъде добавен на по-късен етап, ако проектът изисква еднаква среда за разработка и deployment.

## Consequences / Последствия

Всеки разработчик трябва да има Python и необходимите зависимости локално. Runbook-ът трябва да съдържа точните команди за стартиране и проверка на услугата на порт 8000.
