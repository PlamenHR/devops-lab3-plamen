# 0002. База данни за Упражнение 4
##Status / Статус:## Proposed

## Context / Контекст
За Упражнение 4 Notes API ще има нужда от база данни за постоянно съхраняване на бележките. Трябва да изберем решение, което е лесно за разработка, но може да се използва и при бъдещо разширяване на услугата.

## Options / Варианти
### 1. SQLite
Плюсове:
- Лесна настройка.
- Не изисква отделен database server.
- Подходяща за малки приложения и локална разработка.

Минуси:
- Ограничени възможности при едновременна работа на много потребители.
- Не е най-подходящото решение за по-голяма production система.

### PostgreSQL
Плюсове:
- Надеждна релационна база данни.
- Подходяща за production среда.
- Добра поддръжка на транзакции и едновременен достъп.

Минуси:
- Изисква отделен database server.
- Настройката е по-сложна от SQLite.

## Decision / Решение
За Упражнение 4 ще използваме SQLite, защото е достатъчна за текущите изисквания и позволява лесно локално стартиране без допълнителна инфраструктура.

При бъдещо разширяване на услугата може да се премине към PostgreSQL.

## Consequences / Последствия
Приложението ще може да се стартира лесно на всеки компютър без отделен database server. При преминаване към production среда може да бъде необходима миграция към по-мащабируема база данни.
